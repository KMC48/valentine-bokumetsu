# バレンタイン撲滅委員会 — MVP

学園探索 / 観察 / 通報アクション。スマートフォン縦画面（9:16）向けWebゲーム。

仕様書：`../valentine_annihilation_game_MVP_spec.md`
画像組み込み指示書：`../画像素材/valentine_game_image_integration_guide.md`
UI参考画像：`public/assets/reference/gameplay_reference.png`

## 起動方法

```powershell
cd "$env:USERPROFILE\OneDrive\Desktop\バレンタイン撲滅委員会\app"
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開く。スマホ実機で確認する場合は、
起動時に表示される `Network:` のURL（例 `http://192.168.0.37:5173`）へ
同じWi-Fi内の端末からアクセスする。

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバー起動 |
| `npm run build` | 型チェック＋本番ビルド（`dist/`） |
| `npm run preview` | ビルド結果の確認 |
| `npm test` | ロジックのテスト（vitest） |
| `npm run typecheck` | 型チェックのみ |

## 遊び方

1. タイトル →「はじめから」
2. ストーリーをタップで読み進める
3. ステージで女子生徒をタップ → **観察モーダル**
4. 所持品・仕草・セリフ・観察メモから **友チョコ / 本命チョコ / 無実** を推理
5. 「通報する」か、モーダルを閉じて右下の **通報ボタン**（選択中の生徒が対象）
6. 画面上部のバーで**場所を移動**する（全周回・各ステージ3〜4箇所。移動に8秒かかる）
7. 教室では**机の中を調べられる**（誤認のリスクは無いが12秒かかる）
8. 2・3周目は手がかりが伏せられる。**双眼鏡**で1件ずつ読み取れる（15秒・1ステージ2回）
9. 朝 → 昼 → 放課後 の3ステージ → 最終結果 → エンディング → 次の周回が解放

### 2つのリスクの軸

| 行動 | リスク |
| --- | --- |
| 人物を通報する | **得点**（誤認 -300、コンボ断絶） |
| 机を調べる | **時間**（12秒。空振りでも減点もコンボ断絶も無い） |
| 場所を移動する | **時間**（8秒） |
| 双眼鏡で覗く | **時間**（15秒。1ステージ2回まで） |

「限られた時間をどこに使うか」に判断が集約されるよう、
情報を得る手段はすべて時間で払わせている。

得点は `+100`（友チョコ）／`+500`（本命）／`+1000`（告白直前）／`-300`（誤認）。
連続成功でコンボ倍率（3連続 ×1.2 / 5連続 ×1.5 / 10連続 ×2.0）がかかる。

## デバッグモード

URLパラメータで有効になる（設定画面のチェックボックスでも可）。

| URL | 内容 |
| --- | --- |
| `?debug=true` | 生徒IDとチョコ種別を表示、タイマー無制限、デバッグパネル表示 |
| `?stage=morning` | ストーリーを飛ばしてステージへ直行（`lunch` / `afterSchool`） |
| `?loop=2&stage=lunch` | 周回を指定してステージへ直行 |

デバッグパネルからは、タイマー停止 / +1000pt / ステージ強制終了 / 周回切り替えができる。

{

## 画像素材（2026-09-14 組み込み済み）

生成AI画像21点＋アルファ試行2点＋重複7点（計30ファイル、`../画像素材/`）を組み込み済み。
対応表・配置ルールは `../画像素材/valentine_game_image_integration_guide.md` を参照。

| 種別 | 状態 | 参照元 |
| --- | --- | --- |
| 学校背景6枚・タイトルCG・エンディングCG5枚 | ready（そのまま使用） | `public/assets/backgrounds/`, `endings/` |
| 主人公・教師・男子・女子5人の立ち絵 | ready（背景透過処理済み） | `public/assets/characters/` |
| 通報結果の小物6点 | ready（小物シートから切り出し・透過済み） | `public/assets/items/` |

人物・小物の元画像は「市松模様が画像に焼き込まれたRGB画像」（本物の透過ではない）だったため、
`scripts/remove_checker_bg.py`（外周から4連結でつながる明るいグレー領域だけを背景と判定する方式）で
実際のアルファチャンネルへ変換した。詳細は `public/assets/README.md` を参照。

パスは一元管理：`src/data/assets.ts` の `ASSETS` を経由し、`status` が `"ready"` 以外なら
呼び出し側で仮表示（SVG/CSS）にフォールバックする。新しい画像を追加する場合はここに登録する。

女子生徒45人への立ち絵割り当ては、chocolateType / visibleItem を見て機械的に行っている
（例：本命チョコ系は必ず「箱を隠す」ポーズの立ち絵を使う、など。外見と設定が矛盾しないようにするため）。
割り当てロジックは `students.ts` 生成時に一度だけ適用済みで、各生徒の `image` に直書きされている。

（判定ロジック `suspicionVisibility` は残してある）。

## BGM

納品の3曲を組み込み済み（`サウンド素材/`）。設定画面の音量スライダーで調整でき、localStorageに保存される。

| 曲 | 使用場面 |
| --- | --- |
| ①チョコっと厳戒態勢 | タイトル・周回選択・設定、朝／昼の探索 |
| ②放課後、まだ帰れない | 放課後の探索、最終結果、エンディング |
| ③校則に書いてない感情 | ストーリー画面（主人公の独白） |

実装上の要点：

- **WAVを使っている**（`src/data/bgm.ts` の `BGM_FORMAT` で切り替え可能）。
  納品WAVは「ファイル全体がぴったりループ1周分」（パディング無し）なので、
  バッファ全体をループさせれば**継ぎ目が完全に消える**。
  容量は合計37MB（MP3は4.9MB）。ローカル実行前提なので正確さを優先している。
  配信容量を抑えたい場合は `BGM_FORMAT` を `"mp3"` に変えるだけでよい
  （その場合は資料の「原音の終了秒」で切り詰めてパディングを避ける実装に自動で切り替わる）。
- **ループ終端はハードコードせず `buffer.duration` を使う。**
  ブラウザが 44.1kHz → 48kHz にリサンプリングするため、資料の秒数と微妙にずれる
  （実測：2曲目は資料 68.571429秒 → デコード後 68.571417秒）。
- **Web Audio API を使っている。** `<audio loop>` では曲間のクロスフェードや
  ループ位置の指定ができないため。
- **ブラウザの自動再生制限**があるため、最初のタップ／クリックまで音は鳴らない。
  その操作を拾って再生を開始する（`unlockOnFirstGesture`）。
- **場所移動やモーダルの開閉で曲を頭出ししない。** 同じ曲が既に鳴っていれば何もしない。
- **残り人数やチョコの有無で曲を変えない。** 未発見の情報を音で漏らさないため、
  選曲は「画面」と「時間帯」だけで決めている（`bgmSelect.ts`。テストで検証済み）。

未実装（優先度B/C）：SE（効果音）、キャラクターアニメーション、全方向の自由移動、生徒図鑑、
ミッション一覧、ショップ、ランキング、実績。下部ナビの該当ボタンは枠だけ置いてある。

場所切り替えは**全周回**に対応済み（追加素材0914-b で2・3周目の場所背景が揃ったため）。
学校ごとに別の背景を使っており、同じ絵を使い回していないことはテストで検証している。
