## ファイル仕様・未確認事項

8枚とも **1290×2796 px / PNG / 8-bit RGB / アルファチャンネルなし**。

[Apple公式仕様](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/)（2026年10月27日確認）に1290×2796の縦画像が掲載されています。PNG/JPEGが使用でき、透過・アルファチャンネルは不可、機種サイズごとに1〜10枚です。今回の8枚はこれらの画像ファイル条件に一致します。受理サイズへの適合と、実際のストア審査・アップロード成功は別であり、後者は未確認です。

- 更新した7枚は**ブラウザ再現**。iOS Simulator、署名済みアプリ、TestFlightでは確認していない。
- 維持した1枚は、既存資料にWindowsの`capture.mjs`による制作手順が記載されている。今回実機撮影とは認定していない。
- iOSのWKWebView、Hiragino・Apple絵文字、Safe Area、ステータスバー・ホームインジケータを含む表示との一致は未確認。ブラウザのタッチ・画面倍率設定だけではiOS実機の再現にはならない。
- 「大」「特大」は掲載画像として撮影していない。新設定の保存互換性は既存テストで確認したが、全文章・全サイズの実機レイアウト検証は別途必要。
- App Store Connectの実アカウントでの添付・機種枠の選択・審査は実施していない。アップロード・公開はユーザー承認後に行う。

## 再撮影

[`scripts/store-screenshots/capture.mjs`](../../scripts/store-screenshots/capture.mjs) を使用します。Linuxでは日本語フォントと絵文字フォントが必要です（例：Noto Sans CJK JP / Noto Color Emoji）。OSやフォントが異なると結果も変わります。

```sh
# リポジトリ直下から実行
npm ci --prefix app
npm run build --prefix app
npm ci --prefix scripts/store-screenshots
npx --prefix scripts/store-screenshots playwright install chromium --only-shell
node scripts/store-screenshots/capture.mjs --dist app/dist --out /tmp/valentine-ios-captures
```

スクリプトは本番ビルドをローカルで配信し、撮影後にサーバーとブラウザを終了します。まず一時フォルダに出力して、影響を確認した画像だけ所定フォルダへコピーしてください。
