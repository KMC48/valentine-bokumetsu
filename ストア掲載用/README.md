# ストア掲載用

Google Play / App Store に入力・添付するものをまとめています。
**掲載文とレーティングの下書きは、両方のストアで共通で使えます。**

```
iOS/                              App Store 用（アイコン1024・6.7インチのスクショ8点）
```

iOSのビルド手順は `app/ios引き継ぎ手順.md` を参照してください。

## Google Play 用

Play Console に入力・添付するものをまとめています。

```
アプリアイコン_512.png              アプリアイコン（512×512）
フィーチャーグラフィック_1024x500.png  ストア上部の横長画像
スクリーンショット/                  スマートフォン用（1080×1920、8点）
```

アップロードするAABは `app/android/app/build/outputs/bundle/release/app-release.aab` です。
作り直す手順は `app/android/README.md` を参照してください。

## ストアの掲載情報

### アプリ名（30文字以内）

```
バレンタイン撲滅委員会
```

### 簡単な説明（80文字以内）

```
2月14日の校内で、チョコを持ち込んだ生徒を見抜く観察ゲーム。証拠なき通報は、己を罰する。
```

### 詳しい説明（4000文字以内）

```
「バレンタインなど存在しない。俺はただ、校則を守らせているだけだ」

2月14日。校則第12条「菓子類の持ち込みを禁ずる」を守らせるため、
あなたはバレンタイン撲滅委員会の委員長として校内を巡回します。

■ 見た目では分かりません

生徒をタップすると、持ち物と、その子についての観察メモが手に入ります。
そこから「本命チョコ」「友チョコ」「無実」を見分けてください。

手がかりは、たとえばこんなものです。

・紙袋の底が、中身の重さでたわんでいる
・教科書ケースの厚みが、教材にしては不自然
・校門の教師の前でだけ歩幅が変わった
・「はい、義理ね」と言いながら渡している

■ 間違えれば、あなたが罰せられます

無実の生徒を通報すると減点されます。
確信が持てないなら、見送るのも正しい判断です。

そして、見送った生徒が本当にチョコを持っていた場合も、見逃しとして残ります。
どちらに転んでも痛い。そこを選び続けるゲームです。

■ 学校が変われば、隠し方も変わります

3つの学校を順に回ります。進むほど、見える手がかりが減っていきます。

・1周目 県立桜庭高等学校 ―― 探す。持ち物を見れば、だいたい分かる
・2周目 私立聖蘭学院 ―― 見破る。囮が混ざり、運び屋がいる
・3周目 白鷺台学園 ―― 推理する。当日は誰も持ち歩かない

■ そのほか

・机の中を調べる（時間を消費します）
・双眼鏡で、遠くの生徒の手がかりを1件だけ余分に読み取る
・場所を移動する（移動にも時間がかかります）
・結末は全5種類。あなたのやり方で分岐します

■ 遊び方

通信は不要です。一度インストールすれば、機内モードでも遊べます。
1周は15分ほどです。
```

### カテゴリ

```
ゲーム > パズル
```
※「シミュレーション」でも可。観察と推理が中心なので「パズル」を推奨します。

### タグの候補

```
推理 / 観察 / ノベル / 学園 / 短時間で遊べる
```

## Play Console で聞かれること（下書き）

### コンテンツのレーティング

- 暴力表現：なし
- 性的表現：なし
- 不適切な言葉：なし
- ギャンブル：なし
- ユーザー間のやりとり：**なし**（通信機能がありません）

→ おそらく全年齢または「3+」になります。

### データセーフティ

**このアプリは、利用者のデータを一切収集も送信もしません。**

- 収集するデータ：なし
- 共有するデータ：なし
- 通信：なし（アプリ内に素材を同梱しており、外部へ接続しません）
- データの暗号化：該当なし
- 削除のリクエスト：該当なし

進行状況（解放した周回、到達したエンディング）は端末内にのみ保存されます。

### 広告

なし。

### プライバシーポリシー

データを一切集めていなくても、Play Console は**URLの入力を求めます。**
GitHub Pages に1枚置くのが手軽です。

例：`https://kmc48.github.io/valentine-bokumetsu/privacy.html`
→ このファイルはまだ作っていません。必要になったらお申し付けください。
