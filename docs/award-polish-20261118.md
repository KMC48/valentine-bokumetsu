# 提出前の表示調整（v0.2.6、2026-11-18）

オーナーの指摘3点を直した。

| 指摘 | 原因 | 修正 |
| --- | --- | --- |
| 遊び方の説明で、最後の行が「ぞ。」のように1文字だけになる | 日本語はどこでも改行できるため、画面幅しだいで末尾の1文字が次の行へ送られる | 遊び方の文章は末尾4文字（句読点は数えない）を改行させない（`app/src/game/keepTail.ts`）。ゲーム内の読み物全般に、文節で改行し短すぎる最終行を避けるCSSを追加（`app/src/styles/global.css`） |
| 場所を移動すると絵が少し遅れて出る | 移動のたびに背景・生徒・モブの画像を初めて読み込んでいた | ステージ直前のストーリー中に、そのステージの全場所の画像を読み込んでおく（`app/src/game/preload.ts`） |
| 女の子をタップすると、通報ボタンまでスワイプが要る | 観察画面全体がひとつのスクロールで、ボタンが一番下にあった | 読み物だけをスクロールさせ、保留・見送る・通報するを1行にして下に固定。セリフを横幅いっぱいにし、余白と行間を詰めた（文字の大きさ17pxは維持） |

- 場所移動：ストーリー中に朝の3場所の背景・生徒・モブがすべて読み込まれ、移動直後（約30ms後）に全画像が表示済みだった。
