# 追加画像素材 制作指示書：背景の差し替え（3件）

作成日：2026-09-15
対象：画像生成AI（ChatGPT / DALL·E 等）

既存の背景のうち、**中身が場所の名前と合っていない**ものの作り直しです。

| # | 差し替えるもの | いまの絵 | 点数 |
|---|---|---|---:|
| A | 2・3周目の「体育館裏」 | 校舎沿いの通路にしか見えない | 2 |
| B | 2・3周目の「屋上前」 | ドアのある屋内の廊下。屋上が無い | 2 |
| C | 白鷺台学園の教室の机 | 天板が真っ白で、机に見えない | 1 |

---

## 共通の指定（A・Bに必ず入れてください）

```
【カメラ位置】
そこに立っている人の目線の高さ。見下ろしにも見上げにもしないでください。

【床】
画面の**下半分**を、手前へ続く床にしてください。
ここに女子生徒を立たせるので、物を置いて塞がないでください。

【画面に入れないもの】
・人物（一人も描かないでください。生徒はゲーム側で配置します）
・チョコレート、紙袋、リボン、ハート形のもの

【時間帯】
放課後。**低い位置からの夕日**が差し込み、影が長く伸びている。
空はオレンジから紫へのグラデーション。冬の晴れ。

【画像サイズ】
941 × 1672 px（縦長）
```

> **時間帯の指定は必ず入れてください。**
> いまの2・3周目の放課後の背景は**真っ昼間の青空**で、
> 朝・昼・放課後がすべて同じ明るさになっています。
> 現在はプログラム側で夕方の色を被せてしのいでいますが、
> 夕焼けの絵が届けばそれを外せます。

## A. 体育館裏（2点）

- **出力ファイル名**：`gym_back_loop2.png` / `gym_back_loop3.png`

「体育館裏」は、日本の学校で**告白の定番の場所**です。
人目が無いこと、逃げ場が無いことが絵から伝わる必要があります。

いまの絵は明るく見通しの良い通路で、**隠れる理由がまったくありません。**

```
学校の体育館の裏手を描いてください。

【場所の性質】※ここが今回の依頼の中心です
・**体育館の大きな壁**が、画面の片側にそびえている
　（窓が高い位置にしか無い、のっぺりした大きな壁）
・反対側は、フェンスか、植え込みか、資材置き場でふさがれている
・**行き止まりに近い、細長い空間**であること
・校舎の窓から見えない場所だと分かること
・人ひとり分の細い通路が、手前から奥へ続いている

【置いてよいもの】
・使われていない体操マットや、跳び箱、コーンなどが端に寄せてある
・室外機、雨どい、ホース
・地面には枯れ葉と、溶け残った雪
　※どれも通路の**端**に寄せてください。真ん中は空けてください

【雰囲気】
日陰で、少し湿っている。人に見られない場所。
きれいな場所ではありません。

【構図・時間帯・サイズ】
（上の共通の指定をそのまま入れてください）
```

## B. 屋上前（2点）

- **出力ファイル名**：`rooftop_loop2.png` / `rooftop_loop3.png`

「屋上前」は、**鍵のかかった屋上のドアの前の踊り場**です。
鍵を借りた生徒だけが入れる、という設定が絵の要です。

いまの絵は普通の廊下で、屋上の気配がありません。

```
学校の屋上へ出るドアの前の、最上階の踊り場を描いてください。

【場所の性質】※ここが今回の依頼の中心です
・正面の奥に、**屋上へ出る重い金属製のドア**がある
・ドアには**南京錠と、鍵の管理札**が掛かっている
・ドアの上半分に、すりガラスの小窓があり、**外の夕空が透けて見える**
・ドアの脇の壁に「無断で立ち入ることを禁ず」という古い掲示
・階段を上りきった一番上の踊り場なので、**これ以上は上がれない**
・画面の手前側に、下りの階段の一段目が少しだけ写っている

【雰囲気】
人が来ない場所。埃っぽく、電灯が一つだけ。
ドアのすりガラスから差す夕日だけが明るい。

【構図・時間帯・サイズ】
（上の共通の指定をそのまま入れてください）
※ここは屋内なので、夕日は**ドアの小窓と、階段の窓から**差し込む形にしてください。
```

### 学校ごとの違い

| ファイル | 内装 |
|---|---|
| `rooftop_loop2.png`（私立聖蘭学院） | 濃い木の手すり、古いタイル張りの床、真鍮の照明。ドアは塗装の剥げた緑の鉄扉 |
| `rooftop_loop3.png`（白鷺台学園） | 白い壁とステンレスの手すり。ドアは銀色で、南京錠ではなく**電子ロックのパネル**。掲示は貼り紙ではなく彫り込みのサイン |

## C. 白鷺台学園の教室の机（1点）

- **出力ファイル名**：`classroom_loop3.png`（既存を差し替え）

いまの絵は机の天板が**真っ白**で、質感が無く、机に見えません。
教室全体が白いので、机だけが空間に浮いています。

**構図はいまの絵のままで構いません。机の質感だけを変えてください。**
いまの `classroom_loop3.png` を参照画像として添付してください。

```
添付した教室の絵と、まったく同じ構図・同じ内装・同じ光で、
**机と椅子の質感だけ**を変えて描いてください。

【変えないもの】
・カメラ位置（教室のいちばん後ろの中央通路から黒板を見た構図）
・中央の通路をはさんで左右に机が並ぶ配置
・手前の机が画面の左下・右下の角で切れていること
・白とガラスの内装、大きな窓、差し込む光、床の窓枠の影
・黒板の位置と大きさ

【変えるもの】
机の天板を、**明るいグレーがかったベージュのリノリウム**にしてください。
・真っ白ではなく、わずかに温かみのある色
・表面にうっすらとした木目調のテクスチャがある
・縁に細い濃いグレーの樹脂モールが回っている
・脚は今と同じ細い金属脚（明るいシルバー）
・椅子の座面と背もたれも、天板と同じ色に揃える

【意図】
「白くて清潔」という学校の性格は残したまま、
机に**触れる物としての質感**を与えたいです。
木目調の暖色ではなく、あくまで無機質な素材の範囲で色を付けてください。

【画面に入れないもの】
・人物（一人も描かないでください）
・鞄、紙袋、チョコレート
・黒板への書き込みや掲示物（ゲーム側でポスターを貼ります）

【画像サイズ】
941 × 1672 px（縦長）
```

## 納品後の作業（実装側メモ）

1. `scripts/build_*.py` の要領で配置し、`scripts/optimize_assets.py` でWebP化
2. `src/data/assets.ts` に登録、`src/data/areas.ts` の背景を差し替え

   （夕方の色をプログラムで被せる必要がなくなるため）
4. 新しい絵に合わせて `floor`（床の台形）と生徒の `position` を調整
