# 追加画像素材 制作指示書：校門の横断幕

> **【2026-09-15】納品・実装済み（3点）。**
> 校門に加え、昇降口にも1周目の幕を掛けています。

作成日：2026-09-15
対象：画像生成AI（ChatGPT / DALL·E 等）

---

## いま起きていること

校門に「清く正しく バレンタインのない学校へ」の横断幕を出していますが、
**校舎に掛かっているように見えません。**

理由は、いまの絵が**撮影スタジオで正面から撮った商品写真のような横断幕**だからです。

- 布がまったくたるんでいない（板のように真っ平ら）
- 掛けるための紐が描かれていない（ハトメの穴だけ空いている）
- 壁に落ちる影がない
- 汚れも風のしわもなく、新品すぎる

そのため、校舎の壁に掛かった布ではなく、
**画面に貼られたシール**のように浮いて見えます。

配置は今回コード側で直し、校舎の壁の高さまで上げました。
残っているのは**絵そのもの**の問題です。

---

|---|---|---|

---

## 文言（3点とも共通・一字一句このまま）

```
1行目：清く正しく
2行目：バレンタインのない学校へ
```

2行組みで、**2行目のほうが文字数が多いので横幅が広くなります**。
1行目は中央に寄せ、2行目が横いっぱいに広がる形にしてください。

---

## いちばん大事な指定：**布に見せる**

以下を必ず指示文に入れてください。ここが今回の依頼の中心です。

```
・横断幕は**布**です。板ではありません。
・両端を紐で吊っているため、**中央がわずかに垂れ下がって**います。
　上端が下向きにゆるいカーブを描くようにしてください。
・左右の四隅にハトメ（金属の丸い穴）があり、
　**そこから細いロープが斜め上に伸びて、画面の外へ続いています。**
・布の表面に、風でできた**ゆるい縦じわ**が数本入っています。
・布のすぐ後ろ（下側）に、**壁に落ちた柔らかい影**があります。
・真っ白ではなく、屋外で数年使った**少しくすんだ白**にしてください。
　端に薄い汚れやほつれがあると、なお良いです。
```

> **なぜロープを描くのか**
> 「何かに掛かっている」と見せるには、**掛けている物との繋がり**が要ります。
> ハトメの穴だけだと「穴の開いた紙」にしか見えません。
> ロープが画面外へ伸びていれば、見る人が勝手に「校舎に括り付けてある」と補完します。

## 形とサイズ

```
【縦横比】
横長。**横：縦 = 4：1** にしてください。
※いまの絵（約2.6：1）だと、校舎の壁に対して縦に分厚すぎます。

【画像サイズ】
2048 × 512 px

【余白】
横断幕の本体が画像いっぱいに入るようにしてください。
ただし、垂れ下がりとロープが切れないよう、上下に少しだけ余裕を持たせてください。

【視点】
正面から、目線よりやや見上げた角度。
極端なあおり（真下から見上げる）にはしないでください。
```

---

## 共通の禁止事項

```
【背景】
背景は透過ではなく、#00FF00 の完全な単色（グリーンバック）で塗りつぶしてください。
市松模様（チェッカーボード柄）は絶対に描かないでください。
横断幕の後ろに校舎や空を描かないでください（背景はゲーム側で合成します）。

【その他】
・チョコレートのイラストや禁止マークは入れないでください（文字だけです）
・学校名やロゴを入れないでください
・人物を描かないでください
```

> **壁の影について**
> 「壁に落ちた影」は、横断幕のすぐ外側に**短く**付けてください。
> 背景を描かずに影だけ描くので、布から2〜3cmぶん滲む程度で十分です。
> 長い影を描くとグリーンバック除去のときに一緒に消えてしまいます。

## ③ 3周目：白鷺台学園

- **出力ファイル名**：`banner_wall_loop3.png`

①と同じ指示で、以下だけ差し替えてください。

```
【布と文字】
・白い、印刷された**ターポリン（ビニール製の幕）**。布より張りがある
・表面がわずかに光を反射している
・文字は濃紺の、角の立った現代的なゴシック体（筆文字にしないでください）
・広告代理店に発注したような、洗練されすぎた仕上がり
・しわは少なめ。ただし中央のたるみとロープは必ず描いてください
```

> **③だけ筆文字にしない理由**
> 3周目は「見た目を完璧に整えるエリート校」です。
> 手書きの筆文字より、印刷された無機質なゴシック体のほうが、
> 「本心がどこにもない学校」という気味の悪さが出ます。
