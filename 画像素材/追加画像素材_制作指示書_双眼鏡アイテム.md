# 追加画像素材 制作指示書：双眼鏡アイテム

作成日：2026-09-14
関連：`追加画像素材_制作指示書.md`（本編）／`_机チェック.md`／`_場所切替.md`／`_女子生徒バリエーション.md`
対象：画像生成AI（ChatGPT / DALL·E 等）

---

## 1. 何のための素材か

### 今ある「読み取れない手がかり」という行き止まり

2周目・3周目では、周回難易度によって観察メモの開示数が減ります。

| 周回 | 生徒が持つ手がかり | 読める数 | 読めない数 |
|---|---:|---:|---:|
| 1周目 | 3件 | 3件 | 0件 |
| 2周目 | 3件 | 2件 | **1件** |
| 3周目 | 3件 | 1件 | **2件** |

観察モーダルには、読めない分が次のように表示されます。

> ? 読み取れない手がかりが残っている。この学校では、ここまでしか掴めない。

**ここが行き止まりになっています。** プレイヤーは「読めない情報がある」と知らされるだけで、
それに対してできることが何もありません。

### 双眼鏡でそれを「選択肢」に変える

0914追加でいただいた **`icon_binoculars.png`（双眼鏡アイコン）が未使用**のまま残っています。
これを使って、次のようにする計画です。

> **双眼鏡を使うと、隠れた手がかりを1件開示できる。ただし時間を消費する。**

こうすると、ゲームの3つの軸が揃います。

| 行動 | リスク |
|---|---|
| 人物を通報する | **得点**（誤認 -300、コンボ断絶） |
| 机を調べる | **時間**（12秒） |
| 場所を移動する | **時間**（8秒） |
| **双眼鏡で覗く**（新規） | **時間**（15秒を想定） |

「情報を買うために時間を払うか、勘で通報するか」という判断が生まれ、
2・3周目の“見破る／推理する”というテーマが、制約ではなく駆け引きになります。

## 3. 共通の禁止事項

```
背景は透過ではなく、#FF00FF の完全な単色（マゼンタ）で塗りつぶしてください。
市松模様（チェッカーボード柄）は絶対に描かないでください。
影・グラデーション・模様のない、均一な1色の背景にしてください。
落ち影を描かないでください。
```

## 4. 素材リスト

### B-1. 双眼鏡の視界フレーム ★最優先

双眼鏡を使ったときに画面全体へ重ねる、覗き込んでいる演出用のフレームです。

- **出力ファイル名**：`binocular_view_frame.png`
- **サイズ**：1080 × 1920 px（縦長・スマホ画面全体に重ねる）

```
ゲームの画面全体に重ねる「双眼鏡を覗いた視界」のフレームを描いてください。

【内容】
・画面の中央に、双眼鏡の視界を表す**横長のひょうたん型（円を2つ重ねた形）の穴**
・穴の内側は**完全に透明**にする（後ろのゲーム画面が見える部分）
・穴の**外側は不透明の黒**で塗りつぶす
・穴のふちは、内側に向かってやわらかくぼける（ソフトエッジ）
・ふちのすぐ内側に、レンズの反射を表す薄い水色の細いリング
・穴の中央に、細い十字の照準線（白、半透明）
・左右の円の中心を結ぶ線上に、目盛りの短い線をいくつか（白、半透明）

【重要】
・穴の内側には、ゲーム画面を隠す要素を**何も描かない**でください
・双眼鏡そのもの（筒や本体）は描かないでください。あくまで「覗いた視界」です

【背景】
穴の外側は #000000 の黒、穴の内側は完全な透明にしてください。
マゼンタ等のキー色は使わず、**アルファチャンネル付きのPNG**で書き出してください。
市松模様（チェッカーボード柄）は絶対に描かないでください。

【その他】
・画像サイズは 1080 × 1920 px（縦長）
・穴の横幅は画面幅の約80%、縦幅は画面高さの約35%を目安に、画面の中央やや上に配置
```

> **この素材だけ、キー色ではなく本物のアルファチャンネルでお願いします。**
> 中央を「透明」にする必要があるためです。キー色で塗ると、
> 中央だけ抜くのか外側も抜くのか区別できません。

【その他】
・画像サイズは 512 × 512 px
・ボタンが画像の中央に収まるように

## 5. 実装側の想定仕様（素材制作の参考）

画像を作るときのイメージ用に、どう動く予定かを書いておきます。

### 使い方

1. 生徒をタップして観察モーダルを開く
2. 「読み取れない手がかり」がある場合、**双眼鏡ボタン**が有効になる
3. 押すと `binocular_view_frame.png` が画面に重なり、覗いている演出が入る
4. 隠れていた手がかりが**1件**開示される
5. **15秒**を消費する

### 所持数

- 1ステージにつき **2回まで**（`src/data/score.ts` の定数で調整）
- ステージが変わると回復する
- 残り回数はボタンの右上に数字で出す（CSSで描画するので画像は不要）

### なぜ「時間」を払わせるのか

得点を払わせると、通報の誤認ペナルティ（-300）と役割がかぶります。
時間にしておくと、机チェック・場所移動と同じ土俵で
「限られた時間をどこに使うか」という一本の判断に集約できます。

## 6. 納品時のチェックリスト

- [ ] `binocular_view_frame.png` は**中央が完全に透明**で、外側が不透明の黒
- [ ] `binocular_view_frame.png` の中央に、画面を隠す描き込みが無い
- [ ] `binocular_view_frame.png` は**アルファチャンネル付きPNG**（キー色ではない）
- [ ] 他の素材は**マゼンタ単色**背景
- [ ] **市松模様が描かれていない**
- [ ] 落ち影が描かれていない
- [ ] 指定のファイル名にリネームして `画像素材/` に置いた

---

## 7. 素材が無くても実装は進められます

`binocular_view_frame.png` が無い場合は、CSSの円形グラデーションで
簡易的な覗き込み演出を作れます（机チェックを破線枠の仮マーカーで先行実装したのと同じやり方）。

「双眼鏡の仕組みを先に入れておいて、絵は後から差し替える」も可能です。
その場合はお申し付けください。
