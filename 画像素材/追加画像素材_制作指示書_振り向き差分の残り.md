## 何が足りないか

生徒をタップして狙いを定めると、その子が**こちらを振り返る**演出が入ります。

いま、振り向く絵がそろっているのはここまでです。

| | 01〜05 | **06〜10** |
|---|---|---|
| 1周目（県立桜庭） | ✅ | ✅ |
| 2周目（私立聖蘭学院） | ✅ | ❌ **これが無い** |
| 3周目（白鷺台学園） | ✅ | ❌ **これが無い** |

前回「5種類 × 2校」でお願いしたのですが、そのあと2・3周目も10種類に増えたため、
**増えた5種類ぶんの振り向きが足りていません。こちらの依頼漏れです。**

そのため2・3周目では、**この5人だけタップしても振り向きません。**
ゲームは問題なく動きますが、他の生徒と反応が違うので気になる箇所です。

## 指示文（10点すべてに使えます）

```
参照画像を2枚添付します。

【1枚目】ポーズの見本
　この絵と**まったく同じポーズ・同じ表情・同じ持ち物・同じ髪型**で描いてください。
　歩いている途中で背後から呼び止められ、上半身をひねって
　「えっ？」と振り返った瞬間の絵です。

【2枚目】制服の見本
　この絵と**まったく同じ制服**にしてください。

つまり、1枚目の絵の制服を2枚目のものに差し替えた絵を作ってください。

【変えてはいけないもの】
・顔、髪型、髪色、目の色、表情（驚きと少しの動揺）
・体のひねり方、首の向き、両手の位置
・持ち物の種類・形・色・持ち方
・頭身（7頭身）

【足元】※ここを外すと使えません
**両足とも地面についている状態**で描いてください。
片足を上げたり、跳ねたり、つま先立ちにしたりしないでください。
足の裏が画像の下端ぎりぎりに接するように配置してください。

【背景】
背景は透過ではなく、#00FF00 の完全な単色（グリーンバック）で塗りつぶしてください。
市松模様（チェッカーボード柄）は絶対に描かないでください。
影・グラデーション・模様のない、均一な1色の背景にしてください。
足元に落ち影を描かないでください。

【構図・サイズ】
全身が入る構図（頭のてっぺんから靴の先まで）。
カメラは目線の高さ、正面から。あおり・俯瞰にしないでください。
画像サイズは 1024 × 1536 px（縦長）。
```

---

## なぜ「両足を地面に」が重要か

ゲームは**画像の下端を足元**として床に立たせ、**身長を基準に**拡大縮小します。

片足が浮いていると、基準になるのが「接地している靴底」ではなく
「浮いた靴底」になり、**通常の絵と振り向きの絵で身長が跳ねます。**
タップした瞬間にキャラが伸び縮みして見えてしまいます。

こちら側でも高さを揃える処理を入れていますが、
元から両足がついていれば、その補正が不要になり仕上がりがきれいです。

---

## 3周目（白い制服）の注意

白い制服をグリーンバックで描くと、**輪郭が背景に食われて切り抜きに失敗します。**
3周目の5点には、指示文に次の1行を足してください。

```
白い制服の輪郭が背景に溶けないよう、服の陰影ははっきり付けてください。
```

## 納品時のチェックリスト

- [ ] 背景が**グリーンバック単色**（#00FF00）で、市松模様が無い
- [ ] 落ち影が描かれていない
- [ ] **両足とも地面についている**（片足が浮いていない）
- [ ] **足の裏が画像の下端**に接している
- [ ] 1枚目の見本と**同じ顔・同じポーズ・同じ持ち物**
- [ ] 2枚目の見本と**同じ制服**
- [ ] 08 と 09 は**鞄も紙袋も持っていない**

- [ ] 1024 × 1536 px（縦長）
