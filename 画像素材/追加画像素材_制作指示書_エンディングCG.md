# 追加画像素材 制作指示書：エンディングCGの学校別制服

作成日：2026-09-15
関連：`追加画像素材_制作指示書_主人公の制服.md`
対象：画像生成AI（ChatGPT / DALL·E 等）

---

## 結論：必要です。ただし**いちばん最後で構いません。**

### なぜ必要か

エンディングは**1周ごとに1回**流れます。
2周目（私立聖蘭学院）をクリアしても、3周目（白鷺台学園）をクリアしても、
**1周目の紺の制服のCG**が出ます。

しかもエンディングCGは制服が特に大きく写る絵です。

| CG | 制服の写り方 |
|---|---|
| `ending_s`（完全撲滅） | 主人公が全身で敬礼。紺のブレザーが画面の主役 |
| `ending_a`（生徒指導の右腕） | 主人公の紺ブレザーが大きく写る |
| `ending_b`（そこそこ撲滅） | 主人公＋奥に男女の生徒。3人とも紺 |
| `ending_c`（敗北） | 女子生徒3人が紺のブレザーで大きく写る |
| `ending_special`（特殊） | 女子生徒1人と主人公が向かい合う。2人とも紺 |

**ここは他の生徒の制服も、男子生徒の制服も、まとめて紺です。**

> **前回の訂正**
> 「男子生徒の制服は不要」と申し上げましたが、あれは
> **ストーリー画面の立ち絵**についての話です（男子は一度も喋らないため）。
> **エンディングCGには男子生徒が写っている**ので、そこは別問題でした。訂正します。

### なぜ最後で構わないか

- **10点必要**です（5種類 × 2校）。今ある未着手の中で**いちばん量が多い**
- エンディングCGは**登場人物が複数いて、ポーズも背景も複雑**です。
  制服だけ変えて他は同じ、というのが**いちばん難しい絵**でもあります
- エンディングは1周の最後に一度しか見ないので、**プレイ中の目に触れる時間が短い**

そのため、以下を先に片付けてからで十分です。

1. 2・3周目の「手ぶら」立ち絵（4点）… データと絵が食い違っている
2. 主人公の後ろ姿とバストアップ（4点）… プレイ中ずっと画面に出る
3. 主人公の顔アイコン（4点）… まだ仮の絵
4. 教室背景（3点）／横断幕（3点）
5. **← このエンディングCG（10点）**

## 共通の指示文（10点すべてに入れてください）

```
添付した画像とまったく同じ絵柄・同じ構図・同じポーズ・同じ表情・同じ背景で、
**登場人物の制服だけを別の学校のものに変えて**描いてください。

【変えてはいけないもの】※ここが崩れると使えません
・カメラの位置、画角、人物の立ち位置と大きさ
・全員の顔、髪型、髪色、表情、視線の向き
・全員の手の位置とポーズ
・背景（教室・廊下・校門・空の色・光の差し方）すべて
・**主人公の左腕の白い腕章**（赤い禁止マーク＋板チョコ）。白いまま残してください
・主人公の黒縁メガネと黒いリュック
・チョコレートや紙袋などの小物の形と位置
・スーツ姿の教師（学校が変わっても着替えません）

【変えるもの】
生徒が着ているブレザー・スカート・スラックス・ネクタイ／リボン・校章。
※男子生徒・女子生徒・主人公、**写っている生徒全員**を同じ学校の制服にしてください。
　一人だけ紺のまま残さないよう、画面の隅の人物まで確認してください。

【制服】※どちらか一方を指定
（2周目・私立聖蘭学院）
濃いえんじ色（ワインレッド）のブレザー、胸元に金色の校章。
女子はえんじと紺のチェックのスカートに紺のリボンタイ。
男子はグレーのスラックスに紺のネクタイ。

（3周目・白鷺台学園）
白を基調としたブレザー、襟と袖口に濃紺のライン、胸元に銀色のエンブレム。
女子は濃紺の無地プリーツスカートに細い濃紺のネクタイ。
男子は濃紺のスラックスに細い濃紺のネクタイ。

【背景・サイズ】
背景は**元の絵のまま**描いてください。グリーンバックにはしないでください。
※この絵は切り抜かずに全画面で使うので、他の素材と指定が違います。
画像サイズは 941 × 1672 px（縦長）。
```

> **この10点だけグリーンバックにしない理由**
> 立ち絵は背景を抜いてゲーム画面に重ねますが、
> エンディングCGは**そのまま全画面に表示**します。背景ごと必要です。

## 1点ずつの追加メモ

元の絵で特に崩れやすい箇所を挙げます。参照画像と一緒に伝えてください。

### ending_s（完全撲滅）
```
夕暮れの廊下で、主人公が一人で敬礼している絵です。
・**敬礼している右手の位置と角度**を変えないでください
・窓の外の夕焼けの色を変えないでください
・ここは主人公一人なので、制服の変更も主人公だけです
```

### ending_a（生徒指導の右腕）
```
図書室で、教師が主人公の肩を抱いて親指を立てている絵です。
・**教師はスーツのままです。**着替えさせないでください
・教師の親指を立てた手と、主人公が抱えている濃紺の本を変えないでください
・制服を変えるのは主人公だけです
```

### ending_b（そこそこ撲滅）
```
教室で主人公が机に突っ伏し、奥で男女の生徒がチョコを渡している絵です。
・机の上の**3つの包み（茶・ピンクのチェック・赤）**の形と位置を変えないでください
・**奥の男子生徒と女子生徒も制服を変えてください**（見落としやすい箇所です）
・主人公の頬杖をついた手の形を変えないでください
```

### ending_c（敗北）
```
教室で女子生徒3人がチョコを掲げてはしゃぎ、手前で主人公が突っ伏している絵です。
・**女子3人の制服をすべて**変えてください
・3人が持っているチョコの箱の色と柄を変えないでください
・3人のピースサインと笑顔を変えないでください
・主人公は突っ伏しているので、見えているのは腕章と背中だけです
```

### ending_special（特殊）
```
校門で、女子生徒が主人公にチョコを手渡している絵です。
・**2人とも制服を変えてください**
・受け渡している小さな包みの形と、4本の手の位置を変えないでください
・女子生徒の表情（静かに微笑んでいる）を変えないでください
・背景の校門と夕日を変えないでください
```

## 納品時のチェックリスト

各絵について、**元の絵と並べて**確認してください。

- [ ] 構図・人物の位置・大きさが元の絵と一致している
- [ ] 全員の顔と表情が元の絵と同じ
- [ ] **写っている生徒が全員**同じ学校の制服になっている（隅の人物も確認）
- [ ] 教師がスーツのまま
- [ ] **主人公の腕章が白いまま**で、赤い禁止マークと板チョコが描かれている
- [ ] 主人公のメガネとリュックが残っている
- [ ] チョコ・紙袋などの小物の形と位置が元のまま
- [ ] 背景が元の絵のまま（グリーンバックになっていない）
- [ ] 941 × 1672 px の縦長
- [ ] 指定のファイル名にリネームして `画像素材/` に置いた
