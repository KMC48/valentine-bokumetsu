# 画像素材

納品された画像の原本置き場です。**ゲームが読むのは `app/public/assets/` のほう**で、
ここにあるのは加工前のファイルです。

## フォルダの分け方

納品時のフォルダ名ではなく、**実際にゲームで使われているか**で分けています。
`scripts/organize_source_images.py` を流すと、この形に並べ直せます（何度流しても同じ結果になります）。

```
使用/    … ゲームに組み込み済み。使用シーンごとに分類
未使用/  … 組み込まれていないもの。理由ごとに分類
*.md     … 画像生成AIへの制作指示書（直下に置いたまま）
```

### 使用

| フォルダ | 中身 |
|---|---|
| `02_ストーリー画面のバストアップ` | ノベル調の会話で出る胸から上の絵 |
| `03_エンディングCG` | 結末の一枚絵（3校 × 5種類） |
| `04_背景_1周目（県立桜庭高等学校）` | 校門・教室・購買など |
| `04_背景_2周目（私立聖蘭学院）` | 同上（2周目） |
| `04_背景_3周目（白鷺台学園）` | 同上（3周目） |
| `05_主人公・教師・男子生徒` | 主人公の後ろ姿・顔アイコン・教師 |
| `06_女子生徒の立ち絵` | タップ対象の女子生徒（振り向き差分を含む） |
| `07_モブ生徒` | 背景を歩く／座る／談笑する生徒 |
| `08_掲示物（横断幕・ポスター）` | 校舎の横断幕、菓子持ち込み禁止のポスター |
| `09_UI・アイコン` | ボタンなどの部品 |

### 未使用

| フォルダ | なぜ使っていないか |
|---|---|
| `01_複数枚を1枚にまとめたシート` | 何体ぶんかが1枚に描かれている。切り出した個別ファイルのほうを使っている |
| `02_名前が付いていない納品原本` | `ChatGPT Image …` のまま。中身は他のファイルと重複している可能性が高い |
| `03_下書き・参考用` | 完成前の下書き |
| `04_差し替え前の旧版` | 新しい絵に差し替えたあとの古い版 |

> **`02_名前が付いていない納品原本` の30枚**は、内容を確認できていません。
> 必要なものが埋もれている可能性があるので、捨てる前に一度ご確認ください。

## 加工の流れ

1. 納品ファイルをこのフォルダに置く
2. `scripts/build_*.py` でグリーンバック除去とトリミング
3. **`scripts/optimize_assets.py` でWebPに変換**（PNGのままだと重すぎます）
4. `scripts/organize_source_images.py` でこのフォルダを整理
