# 追加画像素材 制作指示書：アプリアイコン

作成日：2026-09-17
対象：画像生成AI（ChatGPT / DALL·E 等）

> 現在は**暫定のアイコン**が入っています（ゲーム中の禁止ポスターから
> 赤い禁止マークを切り出し、濃紺に乗せたもの）。
> 動作に支障はないので、**急ぎではありません。**

---

## 作るもの：1点

| ファイル名 | サイズ |
|---|---|
| `app_icon.png` | 1024 × 1024 px（正方形） |

この1枚から、アプリ一覧用の各サイズとストア掲載用（512×512）を機械的に書き出します。

---

## いちばん大事な注意：**とても小さく表示されます**

アプリ一覧では **48×48ピクセル程度**まで縮みます。
スマホのホーム画面でも指の爪ほどです。

そのため、以下を必ず指示に入れてください。

```
・要素は**ひとつだけ**にしてください。2つ以上入れると潰れて読めません。
・文字を入れないでください（日本語はこの大きさでは絶対に読めません）。
・線は太く、色数は少なく、明暗の差を強く。
・細かい模様・グラデーション・効果線を入れないでください。
・中央に大きく配置し、外周に少し余白を取ってください。
```

## モチーフ

このゲームの記号は、主人公が左腕に着けている**腕章**です。
白い布地に、**板チョコに赤い禁止マーク**が乗っています。

アプリ一覧でこの赤い丸が見えれば、それだけで何のアプリか伝わります。
参照画像として、`画像素材/使用/08_掲示物（横断幕・ポスター）/sign_no_sweets.png`
（お菓子の持ち込み禁止ポスター）を添付してください。

## 指示文

```
スマートフォンアプリのアイコンを描いてください。

【描くもの】
正方形の画面の中央に、**板チョコに赤い禁止マーク（斜線入りの丸）**が
大きくひとつだけ描かれています。

・板チョコは茶色。四角い枡目が見える、よくある板チョコの形
・板チョコは少し斜めに傾いている
・その上に、太い赤の輪と斜線が重なっている（進入禁止の標識と同じ記号）
・赤い輪は、画面の幅の 65〜70% ほどの大きさ

【下地】
濃紺（#0C1222）の単色。
グラデーション・模様・光の演出を入れないでください。

【描かないもの】
・文字（日本語も英語も入れないでください）
・人物、リボン、ハート、背景の風景
・枠線、影、光沢

【画風】
アプリアイコンとして成立する、はっきりした平面的な絵。
写実的な陰影ではなく、輪郭のはっきりしたイラストにしてください。

【構図】
中央に配置し、外周に画面の 15% ほどの余白を取ってください。
（Androidのアイコンは端末によって丸や角丸に切り抜かれるため、
　端まで描き込むと切り落とされます）

【画像サイズ】
1024 × 1024 px（正方形）。背景は塗りつぶし（透過にしないでください）。
```

## 納品時のチェックリスト

- [ ] **縮小して48ピクセルにしても、何のアイコンか分かる**
      ※納品前にご自身で縮小して確認してください。ここが一番大事です
- [ ] 文字が入っていない
- [ ] 要素がひとつだけ（板チョコ＋禁止マークで「ひとつ」と数えます）
- [ ] 外周に余白がある（丸く切り抜かれても欠けない）
- [ ] 下地が濃紺の単色で、透過になっていない
- [ ] 1024 × 1024 px の正方形

## 納品後の作業（実装側メモ）

1. `画像素材/` に置く
2. `scripts/build_app_icon.py` の `symbol()` を、切り出しではなく
   納品画像をそのまま読む形に差し替えて実行
3. `npm run android:release` で作り直し、`versionCode` を +1
