# バレンタイン撲滅委員会：追加画像素材 制作指示書

作成日：2026-09-14
対象：画像生成AI（ChatGPT / DALL·E 等）に投げるための素材仕様
前提資料：`valentine_game_image_integration_guide.md`（組み込み側の仕様）
比較対象：ゲーム画面イメージ（参考画像）

---

## 0. この文書の使い方

1. 「§3 素材リスト」から作りたい素材を選ぶ。
2. 各素材に書いてある **プロンプト** をそのまま画像生成AIに投げる。
3. できた画像を `画像素材/` に置き、ファイル名を **出力ファイル名** の通りにリネームする。
4. 実装側（Claude Code）に「この素材を追加した」と伝える。データ側のパスを差し替えれば反映される。

**優先度A から順に作れば、参考画像のビジュアルに一番速く近づく。**

---

## 1. 【最重要】すべての素材に共通する禁止事項

過去に生成した素材で実際に起きた問題です。**必ずプロンプトに含めてください。**

### ❌ 市松模様（チェッカー柄）を描かないこと

「背景透過」「transparent background」と指示すると、画像生成AIは
**透過を表す灰色と白の市松模様を“絵として”描き込んでしまいます。**
これは本物の透過ではないので、あとから除去作業が必要になります。

**対策：透過ではなく「単色背景」で出力させる。**

```
背景は透過ではなく、#00FF00 の完全な単色（グリーンバック）で塗りつぶしてください。
市松模様（チェッカーボード柄）は絶対に描かないでください。
影・グラデーション・模様のない、均一な1色の背景にしてください。
```

英語で指示する場合：

```
Use a solid, uniform #00FF00 green screen background.
Do NOT draw a checkerboard/transparency-grid pattern.
No shadows or gradients on the background - flat single color only.
```

> グリーンバックにするのは、キャラの肌・髪・制服（紺・白・茶）と色が被らず、
> あとから機械的に切り抜けるためです。**白背景・灰色背景は不可**
> （白いシャツやワイシャツと区別できなくなります）。

### ❌ 影を床に描かないこと

キャラの足元に落ち影を描くと、ゲーム内で背景に重ねたとき影が二重になります。
影はゲーム側でCSSで付けます。

```
キャラクターの足元に落ち影を描かないでください。
```

### ✅ 全身立ち絵の構図ルール（重要）

複数のキャラを同じ画面に並べるため、**カメラの条件を揃える**必要があります。
バラバラだと、並べたときに身長や目線が合わずに違和感が出ます。

```
・全身が入る構図（頭のてっぺんから靴の先まで）
・足の裏が画像の下端ぎりぎりに接するように配置
・カメラは目線の高さ、正面から。あおり（下から）・俯瞰（上から）にしない
・望遠ではなく標準レンズ相当（パースの歪みを付けない）
・頭身は7頭身で統一
・画像サイズは 1024 × 1536 px（縦長）
```

#### A-1. 主人公の後ろ姿（肩越しショット）★最優先

参考画像で一番目を引く要素です。画面手前に主人公の後頭部と肩が大きく入ることで、
「主人公が廊下を監視している視点」が成立します。

- **出力ファイル名**：`player_back_over_shoulder.png`
- **サイズ**：1024 × 1536 px
- **配置**：ゲーム画面の左下に大きく配置（画面の約45%の幅を占める）
- **構図**：背中側から見た上半身のみ（頭・首・肩・腕章を付けた左腕まで）。腰から下は不要。

```
日本のアニメ風のゲーム用キャラクター素材を作ってください。

【キャラクター】
黒髪で少し寝癖のある男子高校生。黒縁メガネ。
紺色のブレザー制服、白シャツ、青のストライプネクタイ。
黒いスクールバッグを右肩に掛けている。
左の二の腕に白い腕章を巻いており、腕章には「チョコレートに赤い禁止マーク（斜線入りの丸）」が描かれている。

【構図】
カメラに背中を向けた「肩越しショット」。
後頭部・首・両肩・腕章を巻いた左腕までが入る上半身のみ。腰から下は描かない。
顔はほんの少しだけ右を向いていて、頬の輪郭とメガネのつるがわずかに見える程度。
（顔の正面は見えない）
画面手前にいる想定なので、大きく・迫力のある構図で。

【背景】
背景は透過ではなく、#00FF00 の完全な単色（グリーンバック）で塗りつぶしてください。
市松模様（チェッカーボード柄）は絶対に描かないでください。
影・グラデーション・模様のない、均一な1色の背景にしてください。
キャラクターの足元や周囲に落ち影を描かないでください。

【その他】
・画像サイズは 1024 × 1536 px（縦長）
・線画のはっきりしたアニメ塗り
・キャラクターは画像の中央に配置し、上下左右に余白を少し残す
```

## 5. 補足：なぜ「足の裏を画像の下端に」なのか

ゲームでは、生徒を背景の上に「足元の座標」で配置しています。

```
position: { x: 44, y: 72 }   ← 「床の左右44%の位置、画面の上から72%の高さに足の裏が来る」
```

画像の下端＝足の裏として扱うので、足元より下に余白があると、
その分だけキャラが宙に浮いて見えます。

現在の素材は余白が不揃いだったため、実装側で自動トリミング
（`scripts/build_character_variants.py`）をかけて補正しています。
最初から足元を揃えて出力してもらえれば、この補正が不要になり、見た目も安定します。

また、**キャラごとに頭身やカメラ高さが違うと、同じ画面に並べたときに身長が揃いません。**
現在はキャラの「高さ」を基準に拡大縮小しているので、頭身が違うと
同じ身長のはずの生徒が違う大きさに見えてしまいます。
