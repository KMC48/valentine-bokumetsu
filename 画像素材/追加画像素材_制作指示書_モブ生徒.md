# 追加画像素材 制作指示書：モブ生徒（屋内の立ち姿・座り姿）

作成日：2026-09-15
対象：画像生成AI（ChatGPT / DALL·E 等）

---

## いま起きていること

背景を歩いているモブ（通行人役の生徒）は、現在**6人しかいません**。
しかも**全員が「鞄を持って、こちらに背を向けて歩き去る」後ろ姿**です。

そのため、

- **教室の中まで、鞄を持った生徒が下校しているように見える**
- 校舎のどこへ行っても、同じ6人が同じ向きで歩いている
- 誰も立ち止まっておらず、誰も喋っていない。学校に見えない

という状態になっています。

**教室のモブは、いったん非表示にしました。**
下校の後ろ姿しか無く、授業の合間の教室に合わないためです。
この指示書の素材が納品されたら戻します。

## ご質問への回答：座っているカットは背景から作り直すのか？

**いいえ。背景を作り直す必要はありません。**
他の立ち絵とまったく同じ、**グリーンバックの切り抜き**で作れます。

ただし**条件が一つ**あります。

> **机と椅子も、人物と一緒に描いてください。**

理由は、教室の机が**背景画像に描き込まれている**からです。
人物だけを切り抜いて重ねると、背景の机と位置・角度・大きさが噛み合わず、
机をすり抜けて座っているように見えます。

机と椅子ごと1枚の絵にしておけば、**背景の机の上に重ねて隠す**だけで済み、
どこに置いても破綻しません。

```
              ✕ 人物だけ                    ○ 机と椅子ごと
   ┌──────────────┐          ┌──────────────┐
   │  背景の机 ▓▓▓▓▓▓    │          │  背景の机 ▓▓▓▓▓▓    │
   │      人 ← 浮く      │          │   ┌────────┐      │
   │                     │          │   │ 人＋机椅子 │← 重ねて隠す
   └──────────────┘          └──────────────┘
```

## 共通の禁止事項（全10点に必ず入れてください）

```
【背景】
背景は透過ではなく、#00FF00 の完全な単色（グリーンバック）で塗りつぶしてください。
市松模様（チェッカーボード柄）は絶対に描かないでください。
影・グラデーション・模様のない、均一な1色の背景にしてください。
キャラクターの足元や机の下に落ち影を描かないでください。

【絵柄】
添付した既存のキャラクターと同じ絵柄・同じ塗り・同じ制服で描いてください。
制服は紺のブレザー、チェックのスカート（女子）、紺のソックス。

【顔】
モブなので、**顔の描き込みは控えめに**してください。
主役の女子生徒より目立たないよう、表情は薄く、髪型も地味にしてください。
※既存の5人の女子生徒（girl_001〜005）と同じ顔にしないでください。

【カメラ】
目線の高さ、標準レンズ相当。あおり（下から）・俯瞰（上から）にしないでください。
頭身は7頭身で統一してください。

【画像サイズ】
1024 × 1536 px（縦長）
```

参照画像として、**既存の `mob_boy_1.png` `mob_girl_1.png` と `girl_001.png`** を
一緒に添付してください。

## A. 教室で座っている（★最優先・4点）

**机と椅子も一緒に描いてください。** 上の説明のとおりです。

```
【共通の指定】※4点すべてに入れてください
・生徒が、**日本の学校の一人用の机と椅子に座っている**姿を描いてください。
・机と椅子も人物と一緒に、同じ絵の中に描いてください。
　机は木目の天板に銀色の金属脚、椅子も同じ作りです。
・**斜め後ろから見た角度**で描いてください。
　顔は見えても構いませんが、正面顔にはしないでください。
・机の脚の接地面が、画像の下端ぎりぎりに来るように配置してください。
・机の上には教科書とノートだけ。**鞄・紙袋・菓子は置かないでください。**
```

## B. 談笑している（4点・2組）

**2人1組で、向かい合って会話している絵**を、**1人ずつ別々の画像**にしてください。
ゲーム側で2枚を並べて配置します。

```
【共通の指定】※4点すべてに入れてください
・**1枚に1人だけ**描いてください。2人を1枚に描かないでください。
・全身が入る構図。足の裏が画像の下端ぎりぎりに接するように。
・鞄は肩に掛けたままで構いませんが、**手には何も持たせないでください。**
・相手のほうへ体を少し向け、片手で身振りをしています。
・立ち止まって話しているので、歩いている姿にしないでください。
```

| ファイル名 | 指定 |
|---|---|
| `mob_talk_a1.png` | 黒髪のボブ。**向かって右を向いて**話している。口を開けて笑っている |
| `mob_talk_a2.png` | 栗色の三つ編み。**向かって左を向いて**聞いている。口元に手を当てて笑っている |
| `mob_talk_b1.png` | 短髪の男子。**向かって右を向いて**聞いている。片手をポケットに |
| `mob_talk_b2.png` | 明るい茶髪のロング。**向かって左を向いて**話している。両手で身振り |

> **左右の向きを間違えないでください。**
> `a1` と `a2` は向かい合います。両方が同じ方向を向いていると、
> 2人が別々のほうを見て喋っている絵になります。
