## なぜ必要か

現在、**45人の女子生徒を5種類の立ち絵で回しています。**

| 立ち絵 | 使い回している人数 |
|---|---:|
| girl_005（暗紫ロング・閉じた鞄） | **15人** |
| girl_003（お団子ヘア・箱を隠す） | **12人** |
| girl_004（ボブ・眼鏡・教科書） | 8人 |
| girl_001（ポニーテール・ピンクの紙袋） | 5人 |
| girl_002（黒髪ロング・チョコ3袋） | 3人 |

同じ場所に同じ顔が2人並ぶことがあり、**「誰を調べたか」が見分けづらい**状態です。
このゲームは「見た目と行動を突き合わせて推理する」のが核なので、
見分けがつかないことは遊びやすさに直結します。

## 共通の禁止事項（毎回必ず入れてください）

過去に実際に起きた問題への対策です。

```
【背景】
背景は透過ではなく、#00FF00 の完全な単色（グリーンバック）で塗りつぶしてください。
市松模様（チェッカーボード柄）は絶対に描かないでください。
影・グラデーション・模様のない、均一な1色の背景にしてください。
キャラクターの足元に落ち影を描かないでください。

【構図】※他のキャラと並べるので厳守してください
・全身が入る構図（頭のてっぺんから靴の先まで）
・足の裏が画像の下端ぎりぎりに接するように配置
・カメラは目線の高さ、正面から。あおり（下から）・俯瞰（上から）にしない
・望遠ではなく標準レンズ相当（パースの歪みを付けない）
・頭身は7頭身で統一
・画像サイズは 1024 × 1536 px（縦長）
```

> **なぜ「足の裏を画像の下端に」なのか**
> ゲームは「画像の下端＝足元」として床に立たせ、**身長を基準に**拡大縮小しています。
> 足元より下に余白があるとキャラが宙に浮き、頭身がバラバラだと同じ身長に揃いません。

### 既存キャラとの絵柄を揃える

新規キャラを作るときは、**既存の `girl_001.png` 〜 `girl_005.png` を参照画像として一緒に渡し**、
「この5人と同じ絵柄・同じ塗り・同じ制服デザインで、別人を描いてください」と指定してください。

## 納品後の作業（実装側メモ）

1. `画像素材/` に置く
2. `python scripts/build_0914_assets.py` と同じ要領で、グリーンバック除去＋足元トリミング
3. `src/data/assets.ts` の `ASSETS` に登録
4. `src/data/students.ts` の各生徒の `image` を割り当て直す

割り当ては**外見と設定が矛盾しないように**機械的に決めています。

| データ側の条件 | 使う立ち絵 |
|---|---|
| 本命チョコ系 | 箱を隠しているポーズ（girl_003 など） |
| 友チョコ＋紙袋 | 紙袋を持っている絵（girl_001 / girl_002） |
| 弁当箱 | **girl_006（新規）** |
| 部活バッグ | **girl_007（新規）** |
| 手ぶら | **girl_008 / girl_009（新規）** |
| ポーチ | **girl_010（新規）** |

> 例：girl_002 は「チョコを手に持っている」絵なので、
> **無実の生徒には絶対に使いません**（見ただけで答えが分かってしまうため）。
