# 追加画像素材 制作指示書：購買（お菓子が売っている矛盾の解消）

作成日：2026-09-15
対象：画像生成AI（ChatGPT / DALL·E 等）

---

## いま起きていること

1周目の「購買」の背景に、**色とりどりの菓子が並んだショーケース**が描かれています。

このゲームの前提は「校則第12条：菓子類の持ち込みを禁ずる」です。
**その学校の購買が菓子を売っているのは、設定として成り立ちません。**

---

## 結論：ステージを差し替えるより、**購買を「菓子を撤去した購買」にする**のが良いです。

### なぜ差し替えないか

購買は、ゲームとして良い場所です。

- 昼休みに人が集まるので、**受け渡しに紛れ込める**という理屈が立つ
- レジ待ちの列＝人が密集する絵になり、他の場所と画面が変わる

場所そのものを捨てるのは惜しいです。

### なぜ「撤去した購買」が良いか

棚から菓子だけが消え、**貼り紙が貼られている**購買は、
矛盾を消すだけでなく、**主人公がやってきたことの結果**として画面に出ます。

> 「菓子類の販売は当面中止します」

この一枚で、「委員会の活動が学校を変えてしまった」ことが説明なしに伝わります。
矛盾の後始末が、そのまま世界観の補強になります。

**もし差し替えたい場合の代替案は、この文書の末尾に書いてあります。**

---

1周目の1点だけでも矛盾は解消します。

## 構図（既存と揃えるための必須条件）

いまの購買の背景と**同じ画角**にしてください。ここが崩れると人物の足元が合いません。

```
【カメラ位置】
廊下に立って、購買のカウンターを斜め前に見ている視点。
カメラの高さは立っている人の目線。見下ろしにも見上げにもしないでください。

【床】
画面の下半分は、手前へ続く廊下の床。
ここに生徒を立たせるので、物を置いて塞がないでください。

【画面に入れないもの】
・人物（一人も描かないでください。生徒はゲーム側で配置します）
・チョコレート、紙袋、リボン、ハート形のもの

【画像サイズ】
941 × 1672 px（縦長）

【時間帯】
昼休み。窓から高い位置の日差しが差し込んでいる。冬の晴れ。
```

## ① 1周目：県立 桜庭高等学校 ★これだけでも効果があります

- **出力ファイル名**：`shop_loop1.png`

```
日本の高校の購買（売店）を、廊下から見た構図で描いてください。

【カウンターと棚】
・カウンターの上に、パン・おにぎり・サンドイッチが並んでいる
・飲み物の冷蔵ケース（お茶・水・牛乳）がある
・**菓子・チョコレート・スナック類は一切置かないでください**
・ガラスケースの一段が**空になっていて**、そこだけ商品が無い
　（撤去されたことが分かるように、棚板だけが見えている）

【貼り紙】
・その空いた棚のガラスに、白い紙が一枚テープで貼ってある
・紙には手書き風の縦書きで「菓子類の販売は当面中止します」とだけ書かれている
・紙は少し曲がって貼ってあり、角が一つめくれている
　（急いで貼ったように見せてください）

【雰囲気】
・簡素な公立高校の購買。飾り気がない
・にぎやかさよりも、**どこか気まずい静けさ**がある

【構図・サイズ・時間帯】
（上の「構図」の指定をそのまま入れてください）
```

## 【参考】どうしても場所ごと差し替えたい場合

購買をやめる場合、代わりになる「昼休みに人が集まる場所」の案です。
どれも**新しい背景1点＋場所データの追加**で入ります。

| 候補 | 受け渡しの理屈 | 絵の作りやすさ |
|---|---|---|
| **図書室** | 「本に挟んで渡す」が成立する。静かなので挙動が目立つ | ◎ 書架で奥行きが出る |
| **保健室前の廊下** | 「具合が悪い」という口実で人が来る | ○ 他の廊下と絵が似る |
| **自販機コーナー** | 飲み物は禁止されていない。立ち止まる理由になる | ○ 狭い画になりがち |
| **音楽室前** | 部活の名目で集まれる | △ 昼休みに人が集まる理由が弱い |

**おすすめは図書室**です。
「本に挟んで渡す」という受け渡し方が、このゲームの
「見えている持ち物と実際の中身が違う」という軸にそのまま乗ります。

差し替えを選ばれる場合は、その旨をお伝えいただければ
図書室用の指示書と、場所データの追加をこちらで用意します。
