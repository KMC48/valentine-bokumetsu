## A. Dランクの結末「委員会、解散」★必須

### いま起きていること

結末は6種類あり、**Dランクだけ絵がありません。**画面が真っ暗なまま文章だけが流れます。

しかも Dランクは**初めて遊んだ人がいちばん到達しやすい結末**です
（点数が一番低いときの結末なので）。最初に見る結末が真っ暗、という状態です。

### どんな場面か

誤った通報を重ねた主人公が、生徒指導の教師に叱られる場面です。

> 生徒指導・鬼頭「お前、誤認通報が多すぎる。」
> 俺「……疑わしきは報告せよ、という方針でして。」
> 生徒指導・鬼頭「疑わしきは罰せず、だ。**腕章を置いていけ。**」
> ――**腕章は職員室の引き出しに封印された。**
> 俺「……来年、また作ればいい。」
> ――反省の色は、どこにもなかった。

### 1枚で3校ぶんを兼ねます

他の結末の絵は、学校ごとに制服を変えて3枚ずつ作りました。
この絵は**人物の顔も制服も写さない**構図にするので、**1枚で3校とも使えます。**

### 指示文

- **出力ファイル名**：`ending_d.png`

```
日本の高校の職員室にある、灰色のスチール机の引き出しを、
斜め上から見下ろした**手元のアップ**を描いてください。

【写すもの】
・少しだけ開いた机の引き出し
・スーツの袖の、大人の男性の手が、**白い腕章**をその引き出しに入れようとしている
・腕章は白い布で、**板チョコに赤い禁止マーク（斜線入りの丸）**が大きく描かれている
　（添付した主人公の絵の、左腕に巻いている腕章と同じデザイン）
・引き出しの中には、書類の束、朱肉、古いハンコ、使いかけのボールペン
・引き出しの奥に「没収品」と書かれた小さな紙箱

【写さないもの】※ここが大事です
・**人物の顔**（手と袖だけにしてください）
・**生徒の制服**（学校によって制服が違うため、どれか一校の制服が写ると使えなくなります）
・チョコレートや紙袋の実物

【光と雰囲気】
・夕方。窓から差し込む橙色の光が、机の上に斜めに落ちている
・静かで、少し間の抜けた終わり方。深刻すぎる雰囲気にはしないでください
　（主人公は反省していない、という落ちの結末です）

【絵柄】
・添付したエンディングの絵と同じ、アニメ調の塗り

【画像サイズ】
941 × 1672 px（縦長）
背景は描いてください（グリーンバックにはしません。全画面にそのまま表示します）。
```

**参照画像として添付するもの**
- 腕章のデザインの見本：`画像素材/使用/05_主人公・教師・男子生徒/` の主人公の絵
- 絵柄の見本：`画像素材/使用/03_エンディングCG/` のどれか1枚

## B. 生徒会長・一ノ瀬の専用絵（3点）

### いま起きていること

3周目のストーリーに登場する**生徒会長・一ノ瀬**は、同じ3周目の昼休みに
**タップできる生徒としても登場します**（ストーリーの人物に実際に会える、唯一の場面です）。

ところがいまの絵は、**他の生徒と共用の汎用の絵**で、

- 振り返っておどおどしている、内気な子の絵
- **ハート柄のピンクの紙袋**を持っている

となっています。ストーリーの彼女は、

> 「委員会の活動、盛況ですね。」
> 「まさか。私は校則を守る側ですよ。**合法的にね。**」

という、落ち着き払った食えない人物です。**絵と人物像がまったく合っていません。**

さらに、観察メモには「紙袋は**生徒会の資料配布用**」とあるのに、
ハート柄の紙袋はどう見ても贈り物です。**絵のほうが嘘をついている**状態です。

### 人物像

| | |
|---|---|
| 名前 | 一ノ瀬 ひかる（白鷺台学園・生徒会長） |
| 髪 | 黒のストレートロング。前髪は眉の上で切りそろえている |
| 表情 | 口元だけ薄く笑っている。目は笑っていない。余裕がある |
| 服装 | 白鷺台学園の制服（下の表）＋**左腕に「生徒会」の腕章** |
| 持ち物 | **無地の紙袋**（生成り色、生徒会の印が押してある）。口から印刷物の束が少し見えている |

> **腕章について**
> 主人公は「バレンタイン撲滅委員会」の腕章を着けています。
> 彼女にも**「生徒会」の腕章**を着けてもらうと、
> **取り締まる側が2人いる**ことが、絵を見ただけで伝わります。
> 腕章は紺地に白い文字で「生徒会」と入れてください。

> **紙袋について**
> 彼女は**チョコを持っていない（無実の）生徒**です。
> 「バレンタイン当日に、ただ一人堂々と紙袋を持っている」こと自体が罠で、
> 早とちりして通報すると減点されます。
> そのため、紙袋は**怪しいが、贈り物には見えない**ものにしてください。
> ハート柄・リボン・ピンク色は使わないでください。

### 白鷺台学園の制服

- 白を基調としたブレザー、襟と袖口に濃紺のライン
- 胸元に銀色のエンブレム
- 濃紺の無地のプリーツスカート
- 細い濃紺のネクタイ

### 共通の指定（B-1〜B-3すべてに入れてください）

```
【背景】
背景は透過ではなく、#00FF00 の完全な単色（グリーンバック）で塗りつぶしてください。
市松模様（チェッカーボード柄）は絶対に描かないでください。
影・グラデーション・模様のない、均一な1色の背景にしてください。
足元に落ち影を描かないでください。

【白い制服について】
白い制服の輪郭が背景に溶けないよう、服の陰影ははっきり付けてください。

【絵柄】
添付した他の生徒の絵と同じ、アニメ調の絵柄・同じ7頭身。
```

### B-2. 振り向き — `ichinose_turn.png`

生徒をタップしたときに、こちらを振り返る絵です。

```
B-1 の絵とまったく同じ人物・同じ服装・同じ持ち物で、
歩いている途中で背後から呼び止められ、上半身をひねって振り返った瞬間を描いてください。

【表情】※他の生徒と違うところです
他の生徒は驚いて振り返りますが、彼女は**驚きません。**
呼び止められるのを予想していたかのような、落ち着いた薄笑いで振り返ってください。
「何か？」と言いたげな顔です。

【構図】
**両足とも地面についている状態**で描いてください（片足を上げないでください）。
足の裏が画像の下端ぎりぎりに接するように。1024 × 1536 px。

（共通の指定をそのまま入れてください）
```

> **なぜ両足を地面につけるのか**
> 通常の絵と振り向きの絵を切り替えたときに、
> 片足が浮いていると身長が跳ねて見えるためです。

## C. 謎の女子生徒の胸から上（任意）

### いま起きていること

2周目の昼休みのストーリーに、名前の出ない女子生徒が出てきます。

> 謎の女子生徒「ねえ、委員会くん。楽しい？」
> 俺「……誰だ。」
> 謎の女子生徒「さあ。放課後になれば分かるんじゃない？」

いまは**絵が無く**、文字だけが表示されます。

### 顔を隠した絵にします

この人物の正体は、まだ物語の中で決まっていません。
そこで**目元を影で隠し、口元だけ見せる**絵にします。
こうしておけば、後から正体を決めても絵と矛盾しません。

### 指示文

- **出力ファイル名**：`bust_mystery_girl.png`

```
私立聖蘭学院の女子生徒を、腰から上で描いてください。

【制服】
濃いえんじ色（ワインレッド）のブレザー、胸元に金色の校章バッジ、
紺のリボンタイ。

【顔】※ここが大事です
・**目元から上は、前髪と影で完全に隠れている**。目は描かないでください
・口元だけが見えていて、薄く笑っている
・人差し指を唇に軽く当てている（「内緒」のしぐさ）

【髪】
黒に近い濃い色の、肩下までのストレート。

【構図】
腰から上。体はやや斜め。頭のてっぺんを画像の上端近くに。
画像サイズは 1024 × 1536 px。

【背景】
背景は透過ではなく、#00FF00 の完全な単色（グリーンバック）で塗りつぶしてください。
市松模様（チェッカーボード柄）は絶対に描かないでください。
```
