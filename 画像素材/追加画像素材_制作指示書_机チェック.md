# 追加画像素材 制作指示書：机チェック機能

作成日：2026-09-14
関連：`追加画像素材_制作指示書.md`（本編の素材指示書）
対象：画像生成AI（ChatGPT / DALL·E 等）

---

## この機能について

教室（昼休み）ステージに「**机の中を調べる**」を追加しました。

- 生徒を3人に減らし、代わりに調べられる机を2つ置いた
- 机には**誤認通報が無い**（人を疑うわけではないので減点しない）
- 代わりに**1回につき12秒を消費する**。空振りすると時間だけ失う
- → 人物＝**得点**のリスク、机＝**時間**のリスク、という別軸の駆け引き

**現在はダッシュ枠＋虫眼鏡アイコンの仮マーカーで動いています。**
下記の素材が入れば、見た目がゲームらしくなります。

---

## 共通の禁止事項（本編の指示書と同じ）

```
背景は透過ではなく、#00FF00 の完全な単色（グリーンバック）で塗りつぶしてください。
市松模様（チェッカーボード柄）は絶対に描かないでください。
影・グラデーション・模様のない、均一な1色の背景にしてください。
落ち影を描かないでください。
```

> 「背景透過」と指示すると画像生成AIが市松模様を**絵として描き込んでしまう**ため、
> 必ずグリーンバック指定にしてください（過去に実際に起きた問題です）。

## 素材リスト

### D-1. 教室の机（単体・斜め前から）★最優先

背景に描かれている机の上に重ねて、「ここは調べられる」と示すための素材です。

- **出力ファイル名**：`desk_single.png`
- **サイズ**：1024 × 1024 px
- **用途**：ステージ上に配置する机のオブジェクト

```
日本の高校の教室にある「生徒用の机と椅子」を1セット描いてください。
アニメ風、線画のはっきりした塗り。

【構図】
斜め前・少し上から見下ろした角度（俯瞰30度くらい）。
天板の下にある「物入れ（引き出しのない棚状の収納）」の中が、
手前からわずかに覗けるアングルにしてください。
物入れの中は暗く、何が入っているかは分からない程度に。

【デザイン】
・天板は木目調、フレームは銀色のスチールパイプ
・椅子は机とセットで、背もたれは木製
・落書きや傷は入れない（きれいな机）

【背景】
背景は透過ではなく、#00FF00 の完全な単色（グリーンバック）で塗りつぶしてください。
市松模様（チェッカーボード柄）は絶対に描かないでください。
落ち影を描かないでください。

【その他】
・画像サイズは 1024 × 1024 px
・机と椅子が画像の中央に収まるように
```

### D-2. 机の中（空の状態）★最優先

「机を調べた」結果モーダルに表示するインサート画像です。
**チョコは既存の小物素材（`items/chocolate_friend.png` など）を上に重ねて合成する**ので、
この素材には**チョコを描かないでください**。

- **出力ファイル名**：`desk_inside_empty.png`
- **サイズ**：1024 × 768 px（横長）
- **用途**：結果モーダルの背景。この上にチョコ画像を重ねる

```
日本の高校の机の「物入れ（天板の下の収納）」の中を、
正面から覗き込んだ構図で描いてください。
アニメ風、線画のはっきりした塗り。

【内容】
・教科書とノートが数冊、乱雑に重なっている
・プリントの束が奥に押し込まれている
・小さく丸まった消しゴムのカス
・奥の方は暗くなっていて見通せない

【重要】
・**チョコレートやお菓子、紙袋は絶対に描かないでください**
　（当たり・外れの演出はゲーム側でこの絵の上に重ねるため）
・中央付近に、あとから物を重ねられる**空きスペース**を残してください

【構図】
・物入れの開口部が画面いっぱいに入る構図
・手前は明るく、奥に行くほど暗い

【背景】
物入れの内部の絵なので、グリーンバックは不要です。
画像全体が「机の中」になるように描いてください。

【その他】
・画像サイズは 1024 × 768 px（横長）
```

### D-4.【重要】2・3周目の教室背景

**現在、机チェックは1周目の昼休みにしか置いていません。**
理由は、2・3周目の昼休みが**教室ではなく廊下の背景を流用している**ためです
（机を置くと、廊下に机が浮いている絵になってしまう）。

この2枚ができれば、2・3周目にも机チェックを展開できます。

- **出力ファイル名**：`school_loop2_classroom.png` / `school_loop3_classroom.png`
- **サイズ**：941 × 1672 px（既存背景と同じ、縦長）
- **注意**：既存の `school_loop2.png` / `school_loop3.png` を参照画像として渡し、
  **同じ学校の教室**だと分かるようにしてください。

```
添付した画像と**同じ学校**の「教室」を描いてください。
廊下と同じ建材・同じ色調・同じ窓のデザインにして、同一校だと分かるようにしてください。

【構図】
・教室の後ろから、黒板の方を見た構図
・画面の**左半分に生徒用の机が数列並んでいる**（天板の下の物入れが見える角度）
・画面の**右半分は通路**として空けておく（キャラクターを立たせるスペース）
・昼休みの明るい日差しが窓から差し込んでいる

【重要】
・**人物は一人も描かないでください**
・机の上には何も置かないでください（教科書もカバンも無し）
・画面の下半分に「床」がしっかり見える構図にしてください

【その他】
・画像サイズは 941 × 1672 px（縦長）
```

## 納品後の作業（実装側メモ）

| 素材 | 反映先 |
|---|---|
| `desk_single.png` | `src/data/desks.ts` の `image` に `/assets/items/desk_single.png` を設定 |
| `desk_inside_empty.png` | `DeskResultModal` の背景として使用（実装が必要） |
| `ui_search_icon.png` | `DeskTarget` の絵文字🔍と差し替え |
| 教室背景2枚 | `src/data/loops.ts` の `BACKGROUND_TABLE` を差し替え、`desks.ts` に2・3周目の机を追加 |

机の位置・大きさは `src/data/desks.ts` の `position` と `size` で調整できます。

```ts
{
  id: "l1-l-desk-01",
  label: "窓際・後ろから2番目の席",
  position: { x: 10, y: 73 },  // ゲームエリアに対する%（床の台形マッピングは通さない）
  size: 15,                     // ゲームエリア高さに対する%
  content: "friend",            // "friend" | "honmei" | "none"
  resultText: "…",
  clue: "…",                    // 人物ターゲットにつながる手がかり（任意）
}
```

## 納品時のチェックリスト

- [ ] 背景が**単色**（グリーンバック／マゼンタ）になっている
- [ ] **市松模様が描かれていない**
- [ ] 落ち影が描かれていない
- [ ] `desk_inside_empty.png` に**チョコが描かれていない**（重ねる前提のため）
- [ ] 教室背景に**人物が写っていない**、机の上に物が置かれていない
- [ ] 教室背景の右半分が通路として空いている
