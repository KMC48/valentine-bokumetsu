## 共通の指示文（全点に必ず入れてください）

参照画像として**元になる1周目の絵を1枚添付**し、この文章を添えてください。
元の絵は `画像素材/使用/06_女子生徒の立ち絵/` にあります。

```
添付したキャラクターと同じ絵柄・同じ体型・同じ髪型・同じ顔・同じポーズ・
同じ持ち物で、**制服だけを別の学校のものに変えて**描いてください。

【変えてはいけないもの】
・髪型、髪色、目の色、表情、体型
・ポーズ、手の位置
・持ち物（種類・形・色・持ち方をそのままにしてください）

【制服】※下の表からどちらか一方を選んで、ここに書き写してください
（2周目・私立聖蘭学院）
濃いえんじ色（ワインレッド）のブレザー、胸元に金色の校章バッジ、
えんじと紺のチェックのスカート、紺のリボンタイ。

（3周目・白鷺台学園）
白を基調としたブレザー、襟と袖口に濃紺のライン、胸元に銀色のエンブレム、
濃紺の無地のプリーツスカート、細い濃紺のネクタイ。
※白い制服の輪郭が背景に溶けないよう、服の陰影ははっきり付けてください。

【背景】
背景は透過ではなく、#00FF00 の完全な単色（グリーンバック）で塗りつぶしてください。
市松模様（チェッカーボード柄）は絶対に描かないでください。
影・グラデーション・模様のない、均一な1色の背景にしてください。
キャラクターの足元に落ち影を描かないでください。

【構図】※他のキャラと並べるので厳守してください
・全身が入る構図（頭のてっぺんから靴の先まで）
・足の裏が画像の下端ぎりぎりに接するように配置
・カメラは目線の高さ、正面から。あおり・俯瞰にしない
・頭身は元の絵と同じ7頭身
・画像サイズは 1024 × 1536 px（縦長）
```

> **「足の裏を画像の下端に」がなぜ重要か**
> ゲームは画像の下端を足元として床に立たせ、**身長を基準に**拡大縮小します。
> 足元より下に余白があると、キャラが宙に浮きます。

## A. 手ぶらの子（4点）★最優先

| 出力ファイル名 | 参照する元の絵 | 制服 |
|---|---|---|
| `loop2_girl_08.png` | `girl_008.png` | 2周目 |
| `loop2_girl_09.png` | `girl_009.png` | 2周目 |
| `loop3_girl_08.png` | `girl_008.png` | 3周目 |
| `loop3_girl_09.png` | `girl_009.png` | 3周目 |

- `girl_008` … 気だるげにスマートフォンを見ている子。**鞄を持っていない**
- `girl_009` … 両手を広げて手のひらを見せている子（「何も持ってないでしょう？」）

**共通の指示文に、次の1行を必ず足してください。**

```
【重要】
鞄・紙袋・ポーチの類は**一切持たせないでください**。
肩掛けの細いストラップ以外、何も身につけていない状態にしてください。
手ぶらであることが、このキャラクターの設定そのものです。
```

> **なぜ最優先か**
> この2人が演じるのは「手ぶらなのにポケットだけ膨らんでいる子」と
> 「自分では一度も持たない運び屋」です。
> **手ぶらであること自体が、プレイヤーに与える手がかり**になっています。
>
> いまは鞄を持った絵で代用しているため、
> 観察メモに「手ぶら」と書いてあるのに絵では鞄を持っている、
> という食い違いが起きています。推理ゲームとして一番まずい箇所です。

## C. 振り向き差分（10点）

生徒をタップして狙いを定めたとき、こちらを振り返る演出に使います。

| 出力ファイル名 | 参照する元の絵 |
|---|---|
| `loop2_girl_01_turn.png` 〜 `loop2_girl_05_turn.png` | `girl_001_turn.png` 〜 `girl_005_turn.png` |
| `loop3_girl_01_turn.png` 〜 `loop3_girl_05_turn.png` | 同上 |

共通の指示文をそのまま使ってください。
振り向いたポーズ・表情は元の絵のままで、制服だけを差し替えます。

> **枚数が多いので最後で構いません。無くてもゲームは成立します。**
> いまは2・3周目でタップしても振り向かないだけです
> （紺の制服の振り向き絵に化けるのを防ぐため、意図的に無効にしてあります）。

### 振り向きの絵で気をつけること

振り向きポーズは**片足が浮いている**ことがあります。
そのまま出すと、通常の絵と振り向きの絵で身長が跳ねてしまいます。

```
【振り向き差分の追加指定】
両足とも地面についている状態で描いてください。
片足を上げたり、跳ねたりしているポーズにしないでください。
```
