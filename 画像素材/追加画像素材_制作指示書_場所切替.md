# 追加画像素材 制作指示書：場所切り替え（エリア移動）

作成日：2026-09-14
関連：`追加画像素材_制作指示書.md`（本編）／`追加画像素材_制作指示書_机チェック.md`
対象：画像生成AI（ChatGPT / DALL·E 等）

---

## この機能について

自由移動の代わりに「**場所を切り替える**」方式を実装しました。

- 画面上部のバーで場所を選ぶと、その場所へ移動する
- **移動には8秒かかる**（机チェックと同じ“時間のリスク”の軸）
- 各場所には別々の生徒が立っている。全員を見るには回る必要がある
- バーには「その場所に残っている人数」だけを表示する
  （チョコ所持者の数は出さない。出すと推理が不要になるため）

### 現在の実装状況

| 周回 | 朝 | 昼 | 放課後 |
|---|---|---|---|
| **1周目**（公立校） | 校門 / 昇降口・下駄箱 / 中庭 | 教室 / 購買 / 階段の踊り場 | 体育館裏 / 屋上前 / 校門 |
| 2周目（私立聖蘭学院） | 校内（1箇所のみ） | 同左 | 同左 |
| 3周目（白鷺台学園） | 校内（1箇所のみ） | 同左 | 同左 |

**1周目だけが場所切り替えに対応しています。**
理由は、0914追加でいただいた `place_gate` `place_courtyard` `place_stairs` `place_shop` が
**1周目の公立校の校舎**で描かれているためです。
2・3周目でこれを使うと、別の学校なのに同じ校門・同じ中庭が出てきてしまいます。

下記の素材が揃えば、2・3周目も同じ仕組みで場所切り替えに対応できます。
**実装側の変更はデータ1ファイル（`src/data/areas.ts`）の追記だけ**で済みます。

## 共通の禁止事項

```
・人物は一人も描かないでください（キャラクターはゲーム側で重ねます）
・画面の下半分に「地面・床」がしっかり見える構図にしてください
　（生徒を立たせるスペースとして使うため）
・消失点が画面の中央やや上に来る、奥行きのある構図にしてください
・画像サイズは 941 × 1672 px（縦長）
```

> 背景素材なのでクロマキー（グリーンバック）は不要です。
> 「人物なし」「床が見える」の2点だけ厳守してください。

### E-4. 時間帯差分（優先度は低い）

現在、場所背景はすべて「朝の光」で描かれているため、
昼・放課後に同じ場所へ行っても光が朝のままです。

厳密にやるなら各場所 × 3時間帯が必要ですが枚数が多くなるため、
**まずは「放課後（夕方）」だけ**あれば十分です。

| 出力ファイル名 |
|---|
| `place_gate_after.png` |
| `place_courtyard_after.png` |

```
添付した画像と**まったく同じ場所・同じカメラ位置**を、夕方の光で描いてください。
建物の構造・配置は完全に同じにしてください。
西日がオレンジ色に差し込み、地面に長い影が伸びています。空は茜色。

【重要】
・人物は一人も描かないでください
・カメラの位置・画角は添付画像と完全に同じにしてください
・画像サイズは 941 × 1672 px（縦長）
```

## 納品後の作業（実装側メモ）

`src/data/areas.ts` に場所を追加し、`STAGE_AREAS` に並べるだけです。

```ts
// 1. 場所を定義
{
  id: "loop2Gate",
  label: "校門",
  hint: "登校してくる生徒が必ず通る。",
  background: ASSETS.loop2Gate.src,
  focusY: 66,            // 背景の縦の見せ方。大きいほど床側が映る
  floor: OUTDOOR_FLOOR,  // 生徒が立てる床の台形
},

// 2. ステージに割り当て
2: {
  morning: ["loop2Gate", "loop2Entrance", "loop2Courtyard"],
  ...
}
```

そのあと `scripts/assign_areas.py` を実行すると、生徒がその場所へ振り分けられます。
