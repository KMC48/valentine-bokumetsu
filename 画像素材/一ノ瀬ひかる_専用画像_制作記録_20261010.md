## 再加工

リポジトリ直下で実行する。Python依存は Pillow / numpy / opencv-python-headless。

```bash
python scripts/build_ichinose_assets.py
python scripts/optimize_assets.py
python scripts/organize_source_images.py
python scripts/assign_character_images.py
python scripts/test_assign_character_images.py
npm --prefix app test
npm --prefix app run build
```

`build_ichinose_assets.py` は専用原稿3点だけを扱う。汎用画像へ書き込まない。
髪の間・腕・紙袋の持ち手の内部の緑も除去する。この3原稿に緑色の服・瞳・持ち物はない。
通常絵と振り向きは余白を除き、既存の高さ指定と足元アンカーを使う。
素材整理スクリプトは専用立ち絵を「06」に、バストアップを「02」に維持する。
使用または未使用のフォルダがまだ無い新規cloneでも、整理結果の表示が失敗しないよう修正した。

## 上書き防止と互換性

`assign_character_images.py` は `l3-l-05` の出力を専用名に固定する。
汎用画像の割当カウンタは従来どおり進めるため、後続の生徒の絵が連鎖的に変わらない。
現行データは43人。専用絵を除く42人の画像と、全員の判定・ヒント等を保持する。
`stories.ts`、得点・通報・分岐・ゲーム状態の処理は変更していない。
一ノ瀬は引き続きチョコなし。通報は誤認（-300点、コンボ解除）。

ストーリーの対応は「3周目」かつ話者名が「生徒会長・一ノ瀬」に完全一致したときだけ。
主人公・教師・男子生徒・ナレーション・謎の女子生徒の既存表示を保持する。
